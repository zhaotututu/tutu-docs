# Tutu Docs

Welcome to the public English documentation for Tutu products.

This documentation covers public user-facing guides for TutuTrainer, Tutu Super Smart Tagger, Tutu Video Publisher, Tutu Video Prompt Tool, and related AIGC utilities. It is intended for users who need installation guidance, first-run setup, feature explanations, workflow notes, and troubleshooting help.

Official website: https://zhaotutu.xyz

## Products

- [TutuTrainer](products/tutu-trainer/overview.md): a Windows application for LoRA model training and model workflow management.
- [Tutu Super Smart Tagger](products/tutu-super-smart-tagger/overview.md): an AI-assisted image and video captioning workspace for creators and dataset builders.
- [Tutu Video Publisher](products/tutu-video-publisher/user-guide.md): a video publishing and account workflow assistant.
- [Tutu Video Prompt Tool](products/tutu-video-prompt-tool/overview.md): a prompt expansion tool for text-to-video and image-to-video creation.
- [Tutu AIGC Toolbox](products/tutu-aigc-toolbox/overview.md): a public overview of the broader Tutu AIGC toolset.

## Download Safely

Always download installers, update packages, and related tools from the official website or clearly announced official channels. Avoid unofficial repackaged installers, modified scripts, or marketplace resales.

## Documentation Scope

This repository contains public product documentation only. It does not contain application source code, internal implementation details, private credentials, or unreleased internal notes.

These English docs were migrated and rewritten from public product documents on June 4, 2026. Internal drafts, historical files, spoken-video scripts, empty-title notes, and non-product notes were intentionally excluded.
