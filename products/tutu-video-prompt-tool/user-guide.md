# Tutu Video Prompt Tool User Guide

This guide explains the normal workflow for using Tutu Video Prompt Tool.

## 1. Choose a Mode

Select the mode that matches your generation task:

- Text-to-video: start from a written idea.
- Image-to-video: start from an image and generate a motion-oriented prompt.

## 2. Enter Your Base Idea

Write a short idea in plain language.

Good base ideas include:

- Subject.
- Action.
- Scene.
- Mood.
- Style.

Example:

```text
a girl walking through a rainy neon street
```

## 3. Choose a Style Template

Available templates may include:

- Standard.
- Cinematic.
- Realistic.
- Anime.
- Other templates provided by the installed version.

The template influences how the tool adds camera, lighting, texture, motion, and style details.

## 4. Generate the Expanded Prompt

Run generation and review the output.

Check whether the prompt:

- Keeps the original idea.
- Adds useful scene and motion details.
- Avoids contradictions.
- Is not too long for your target video model.
- Does not include unwanted sensitive or restricted content.

## 5. Save and Reuse

Use the prompt library or history to keep useful prompts. Organize prompts by time, type, or project so you can reuse the ones that work.

## 6. Apply to a Video Model

Copy the prompt into your video generation tool and test it. If the result is not stable, adjust:

- Camera movement.
- Subject action.
- Scene complexity.
- Style keywords.
- Lighting.
- Prompt length.

## Tips

- Start simple, then add details.
- Compare several generated prompts for the same idea.
- Keep the prompts that produce consistent results.
- Do not rely on a single prompt for every video model.
- If using an API-based model configuration, protect your API key.
