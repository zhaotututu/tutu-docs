# Tutu Video Prompt Tool Overview

Tutu Video Prompt Tool is a desktop prompt expansion tool for text-to-video and image-to-video creation. It helps users turn short ideas into richer prompts with scene, camera, lighting, style, and motion details.

Official website: https://zhaotutu.xyz

## Core Features

- Text-to-video prompt expansion.
- Image-to-video prompt expansion.
- Multiple style templates such as standard, cinematic, realistic, and anime-oriented modes.
- Prompt history and prompt library management.
- AI-assisted naming.
- One-click apply or copy, depending on the installed version.
- Dark and light theme support in the described V2.0 release.

## Who It Is For

Use this tool if you:

- Create AI videos from short text ideas.
- Need more complete camera, motion, lighting, and style prompts.
- Want to reuse and organize prompt history.
- Prefer a desktop workflow instead of repeatedly writing prompts from scratch.

## Example

Short idea:

```text
a kitten running and jumping
```

Expanded prompt direction:

```text
a playful kitten running and jumping through a sunlit room, dynamic camera movement, soft natural light, detailed fur, lively motion, cinematic composition
```

Always review expanded prompts before sending them to a video generation service.

## Practical Notes

- Generated prompts are suggestions, not guaranteed results.
- Different video generation models respond differently to the same prompt.
- Shorter prompts may work better for some models; detailed prompts may work better for others.
- Keep a prompt history so you can compare what actually worked.
