# Tutu Super Smart Tagger Overview

Tutu Super Smart Tagger is an image and video material organization tool for AIGC creators. It brings image prompt reverse captioning, natural-language descriptions, paired-image captioning, batch processing, Creative Workshop, AI Lab, video reverse prompts, and element editing into one desktop workstation.

Official download site: https://zhaotutu.xyz

Open the official site and choose the Super Smart Tagger installer from the download area. The official site and cloud-drive download entry are updated together.

## What It Is For

Use Tutu Super Smart Tagger when you need to:

- Prepare images for LoRA training.
- Generate or review captions in batches.
- Create natural-language image descriptions.
- Build paired source/result descriptions for image editing datasets.
- Understand local or online videos.
- Generate video scene descriptions, summaries, and spoken-script style notes.
- Manage captioning projects and export results.
- Remove or process fixed video elements such as watermarks, subtitles, logos, and fixed screen regions.

## Recommended Workflows

For image training datasets:

Project Management -> Image Prompt Reverse Captioning -> Prompt Phrase Mode or Natural Language Mode -> Batch Generate -> Export.

For image editing datasets:

Project Management -> Image Prompt Reverse Captioning -> Reference Reverse Captioning -> Pair source and result images -> Generate paired descriptions.

For video understanding:

Video Prompt Reverse Captioning -> Import local video or online video -> Open the detail page -> Generate scene descriptions, summaries, and spoken scripts.

For batch video organization:

Video Prompt Reverse Captioning -> Select multiple videos -> Batch reverse prompts -> Batch export.

For video element processing:

Video Detail Page -> Element Editor -> Automatic recognition or manual box selection -> Download or verify local models -> Start processing.

## Default AI vs Custom Models

New users can start with the default AI. Advanced users can configure:

- External model APIs.
- Local models.
- Custom compatible endpoints.
- API keys from their own providers.

Never paste API keys into untrusted tools. Only configure keys inside the official application when you understand the provider and billing rules.

## Important Notes

- Default AI uses credits. A successful request writes transaction history after success. Multi-content video analysis tries to reduce repeated uploads and repeated charges.
- Local element processing depends on GPU and model files. If models are missing, download them according to the prompts in the interface.
- Installers, update packages, user guides, and troubleshooting notes should be treated according to the newest official website and public documentation.
