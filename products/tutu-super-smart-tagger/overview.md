# Tutu Super Smart Tagger Overview

Tutu Super Smart Tagger is an AI-assisted desktop workspace for organizing image and video materials. It helps creators generate captions, prompt phrases, natural-language descriptions, paired image descriptions, video summaries, scene descriptions, and batch exports for AIGC workflows.

Official website: https://zhaotutu.xyz

## What It Is For

Use Tutu Super Smart Tagger when you need to:

- Prepare images for LoRA training.
- Generate or review captions in batches.
- Create natural-language image descriptions.
- Build paired source/result descriptions for image editing datasets.
- Understand local or online videos.
- Generate video scene descriptions, summaries, and spoken-script style notes.
- Manage captioning projects and export results.

## Current Public Capabilities

The source document describes version 1.1.7 with the following public features:

- Account login and registration by email.
- Account center for credits, subscriptions, device authorization, activation status, invitation codes, and transaction history.
- Default AI for users who do not want to configure custom models first.
- Image workflows for prompt tags, natural-language captions, paired reverse captioning, tag filtering, batch processing, and export.
- Video workflows for local video import, online video link recognition, scene descriptions, summaries, spoken-script notes, batch reverse captioning, and batch export.
- Element editor with automatic recognition and manual selection for items such as watermarks, subtitles, or fixed screen regions.
- Model configuration for default AI, external APIs, local models, and compatible custom endpoints.
- Dark mode, system-language following, task-style model downloads, update feedback, batch result views, and clearer error messages.

## Recommended Workflows

For image training datasets:

1. Create or open a project.
2. Import images.
3. Generate prompt phrases or natural-language captions.
4. Review and edit the results.
5. Export captions for training.

For image editing datasets:

1. Pair source images and result images.
2. Use paired reverse captioning.
3. Review the generated description.
4. Export the paired dataset.

For video understanding:

1. Import local videos or paste online video links.
2. Open the video details page.
3. Generate scene descriptions, summaries, or spoken-script notes.
4. Review and export results.

For batch video organization:

1. Select multiple videos.
2. Choose the content types to generate.
3. Run batch processing.
4. Export the generated results.

## Default AI vs Custom Models

New users can start with the default AI. Advanced users can configure:

- External model APIs.
- Local models.
- Custom compatible endpoints.
- API keys from their own providers.

Never paste API keys into untrusted tools. Only configure keys inside the official application when you understand the provider and billing rules.
