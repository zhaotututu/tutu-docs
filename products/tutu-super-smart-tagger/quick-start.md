# Tutu Super Smart Tagger Quick Start

This quick start focuses on the current user-friendly path: install the app, log in, use the default AI first, and configure advanced models only when needed.

## 1. Install and Open

1. Download the installer from https://zhaotutu.xyz.
2. Install the application.
3. Open it from the desktop or Start menu.
4. Wait for the first launch to finish.

## 2. Log In or Register

The current product flow uses an account center.

- If you already have a Tutu account, log in directly.
- If you do not have an account, use the registration flow.
- The same Tutu account system can be shared across supported Tutu products.

After login, open the account page to review credits, device status, subscription status, and transaction records.

## 3. Start with Default AI

New users do not need to configure an API key first.

Use the default AI for:

- Image prompt reverse captioning.
- Natural-language image descriptions.
- Paired image descriptions.
- Video understanding.

If you need a custom model, external API, or local GPU model, configure it later in system settings.

## 4. Create an Image Captioning Project

1. Open project management.
2. Create a new image project.
3. Import images.
4. Choose a captioning mode:
   - Prompt phrases.
   - Natural-language captions.
   - Paired source/result descriptions.
5. Run generation.
6. Review and edit results.
7. Export captions.

## 5. Create a Video Understanding Project

1. Open the video reverse-captioning area.
2. Create or select a project.
3. Import local videos or paste online video links.
4. Generate scene descriptions, summaries, or spoken-script notes.
5. Review and export results.

## 6. Configure Advanced Models Only When Needed

Use system settings if you want to connect:

- Your own API key.
- A local model.
- A custom compatible endpoint.
- A specialized vision or language model.

If a local model workflow mentions Ollama, confirm that Ollama is installed and running in the background before using that specific local-model mode. This is optional for users who use the default AI.

## 7. Export Results

After generation, export captions or analysis results in the format required by your training or production workflow. Review the exported files before using them in training.

## Practical Tips

- Review AI-generated captions before training.
- Keep dataset folder names simple and stable.
- Do not mix unrelated image groups in one project unless that is intentional.
- Store API keys securely.
- Use the official website for updates.
