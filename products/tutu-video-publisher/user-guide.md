# Tutu Video Publisher User Guide

Tutu Video Publisher is a workflow tool for managing video publishing tasks, platform accounts, posting plans, dashboard status, and AI-assisted analysis.

Source document version: v1.1.8, updated April 13, 2026.

Official website: https://zhaotutu.xyz

## What It Does

Tutu Video Publisher helps users organize video publishing workflows across supported platforms.

Public user-facing functions include:

- Account and credit management.
- Platform account management.
- Publishing plans.
- Dashboard status.
- AI-assisted analysis.
- System settings.

## Quick Start

1. Install the application from the official website.
2. Open the application.
3. Log in or register.
4. Open the account page to check credits and account status.
5. Add platform accounts according to the app's supported login method.
6. Create a publishing plan.
7. Review scheduled or pending tasks from the dashboard.

## Account and Credits

The account area is used to view account status, available credits, and related records. If the app shows a server-side account state, treat the in-app account page as the source of truth.

## Platform Account Management

Supported platforms may use different login methods. Some platforms use browser login, cookies, or token-like session data.

Safety rules:

- Only enter platform account information inside the official application.
- Do not publish screenshots that expose cookies, tokens, session values, account IDs, or private links.
- If you suspect session data was exposed, log out from the platform and refresh or revoke the session if the platform allows it.
- Platform login state can expire; refresh it when the application prompts you.

## Publishing Plans

A publishing plan organizes what content should be posted and when.

Before publishing:

- Check video file paths.
- Check titles, descriptions, tags, and cover settings.
- Check target platform accounts.
- Check schedule time.
- Confirm that the content complies with each platform's rules.

## Dashboard

Use the dashboard to monitor:

- Pending tasks.
- Running tasks.
- Completed tasks.
- Failed tasks.
- Account status reminders.
- Credit or service status where supported.

## AI-Assisted Analysis

AI analysis can help summarize or inspect video content depending on the installed version and configured services.

Review AI-generated output before using it in public posts. AI summaries may miss context, platform-sensitive wording, or small visual details.

## System Settings

Use settings to configure application behavior, language, account-related options, and platform workflow preferences available in your installed version.

## Common Issues

### Platform Login Expires

Reopen the platform account area and refresh the login state. Some platforms expire sessions automatically.

### A Publish Task Fails

Check:

- Whether the platform account is still logged in.
- Whether the video file still exists.
- Whether title, description, cover, and tags meet platform requirements.
- Whether network access is stable.
- Whether the platform changed its upload rules.

### AI Analysis Fails

Check:

- Account credits.
- Network access.
- Configured model or default AI availability.
- File size and supported media format.

## Compliance Reminder

Only publish content you have the right to publish. Follow each platform's rules and local laws. Do not use the tool to automate spam, impersonation, fraud, or prohibited content.
